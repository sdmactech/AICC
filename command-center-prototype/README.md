# AI Empire Command Center Prototype

This folder contains the clickable prototype for the AI Empire Command Center / AI Workforce Command Center.

## Current Prototype Scope

- Company Map as the default homepage
- Five company/division buildings
- Immersive company floor views
- Pixel-art department-specific AI agents
- Desks/workstations
- Agent state indicators
- Inspector panel
- Dashboard
- Governance rules
- Build plan
- Approval inbox
- Project Ops tracking

## Local Preview

From this folder, run:

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.
